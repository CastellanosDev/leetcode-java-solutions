# ☕ leetcode-java-solutions

Solutions to LeetCode problems in Java, organized by difficulty level.

Each solution includes the approach explanation, time and space complexity, and a working `main()` method so you can run it directly from IntelliJ without any extra setup.

```
├── medium/

│   │   └── Solution.java
│   └── ...
└── hard/
    └── ...
```

---

## 🚀 How to Run

1. Open the project in IntelliJ IDEA
2. Navigate to the solution you want to run (e.g. `src/easy/two_sum/Solution.java`)
3. Right-click on the class name → **Run `Solution.main()`**

No Maven, no dependencies. Pure Java.
